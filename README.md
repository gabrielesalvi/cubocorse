# Cubo Corse — versione giocabile

Gioco di corse GT in voxel nel browser, con Monza in scala 1:1. Un progetto di Gabriele Salvi.

**Gioca:** https://cubocorse.gabrielesalvi.com

Questo repo contiene solo la copia pronta da giocare, pubblicata con GitHub Pages.
Il codice sorgente sta in un repo privato. Mappa di Monza: © OpenStreetMap contributors.

Per aggiornare: `./pubblica.sh "messaggio"` (importa l'ultimo commit del gioco e pubblica).
